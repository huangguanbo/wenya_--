## 核心业务流程

### 1. 用户注册流程

```
用户填写信息 → 监护人手机验证 → 创建监护人记录 → 创建用户账号
                                           ↓
                                    创建用户画像 + AI 记忆
                                           ↓
                                    记录合规日志 ← 保存同意记录
```

### 2. 写作评分流程

```
用户提交作文 → 内容安全检查 → AI 评分服务 → 七维度打分
                                              ↓
                                       计算加权总分
                                              ↓
                                       生成 AI 评语 + 建议
                                              ↓
                                       记录算法日志 ← 保存决策因子
                                              ↓
                                       更新用户画像 ← 同步成长数据
```

### 3. AI 对话流程

```
用户发送消息 → 内容安全检查 → 获取 AI 记忆 → 构建对话上下文
                                              ↓
                                       调用 LLM API
                                              ↓
                                       AI 响应内容安全检查
                                              ↓
                                       保存对话记录 ← 更新记忆
                                              ↓
                                       记录合规日志 + 算法日志
```

### 4. 排行榜计算流程

```
定时任务触发 → 获取同年级用户 → 计算各项指标 → 生成百分位排名
                                              ↓
                                       应用防伤害机制
                                       (前 50%/20% 可见)
                                              ↓
                                       更新排行榜记录 ← 写入历史表
                                              ↓
                                       用户查看排名 (可选退出)
```

## 安全与合规模块

### 内容安全过滤链

```
用户输入 → 敏感词检测 → 长度验证 → 第三方 API 审核 (可选) → AI 处理
                                                          ↓
AI 输出 → 敏感词检测 → 拟人化检查 → 安全回复替换 (如有问题) → 返回前端
```

### 日志审计系统

```
所有关键操作 → ComplianceLog 表 (6 个月保存期)
AI 算法决策 → AlgorithmLog 表 (永久保存)
                      ↓
               支持一键导出 ← 网信办审计要求
```

## 响应式设计策略

### PC 端 (≥1024px)
- 双栏布局：左侧 AI 对话 + 右侧编辑器
- 完整导航栏 + 侧边工具栏
- 大尺寸图表展示

### 平板端 (768px-1023px)
- 可切换的双栏/单栏布局
- 折叠式导航
- 中等尺寸图表

### 移动端 H5 (<768px)
- 单栏布局 + Tab 切换
- 底部导航栏
- 触摸友好的大按钮
- 简化图表展示

## 性能优化

### 前端
- Vite 构建 + 代码分割
- ECharts 按需加载
- 图片懒加载
- 接口请求缓存

### 后端
- 数据库索引优化
- Redis 缓存热点数据
- 限流保护 (Flask-Limiter)
- 异步任务（可选 Celery）

### 数据库
- 作文表按用户 ID 分区
- 排行榜定期物化
- 日志表定期归档
